# 3. Web Viewer — Proxy Matrix Analyzer (`3-web-viewer`)

Static web application (pure HTML + CSS + JS, no backend or build step) that can be:
- hosted on any static web server (Nginx, Apache, GitHub Pages, Cloudflare Pages), **or**
- opened directly from disk (`index.html` via `file://` — works using the auto-generated `data/server-pings.js`).

## Features

1. **Server-to-server matrix loading**:
   - Automatically fetches `data/server-pings.json` (over HTTP/HTTPS) or `data/server-pings.js` (locally over `file://`).
   - Also lets you load any `server-pings.json` file via the **Load server-pings.json** button in the top bar.
2. **Player ping input**:
   - Accepts `my-pings.json` generated by `ping-servers.bat` / `ping-servers.php`, pasted from clipboard or uploaded from disk.
   - Also supports simple text formats (`1.2.3.4=35`, `1.2.3.4: 35ms`) and manual per-server editing.
3. **Best proxy summary**:
   - Shows the best proxy for each target server, path breakdown (`You→Proxy + Proxy→Target`), gain/loss in `ms` and `%`, and top alternatives.
4. **Every-to-every matrix (`Proxy × Target`)**:
   - Sticky top and left headers for navigating large server lists.
   - Multiple cell display modes (full breakdown, `+/- ms` delta only, total via proxy, server↔server only).
   - Row/column filters, gain threshold (`1/5/10/20 ms`), metric selector (`avg` / `median` / `min`), axis swap, and reverse-direction fallback when one direction is missing.
   - Built-in `EN / PL` language switcher (English by default).
